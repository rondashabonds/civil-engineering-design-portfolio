## Viewing the Models & Animations

Each OpenSCAD project includes a built-in 360° camera animation.

To view a project:

1. Download and open the `.scad` file in OpenSCAD.
2. Press **F5** to preview the model.
3. Select **View → Animate**.
4. Set **FPS** to `30`.
5. Set **Steps** to `180`.
6. Play the animation to view the project from multiple angles.

The animation uses OpenSCAD's built-in `$t` variable, which progresses from `0` to `1` throughout the animation cycle.
