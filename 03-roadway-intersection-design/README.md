# Roadway / Intersection Design

## Project Overview

This project is a conceptual four-way roadway intersection created in OpenSCAD to explore fundamental transportation-engineering and roadway-design concepts.

The model combines vehicle infrastructure, pedestrian facilities, traffic-control elements, pavement markings, and conceptual roadway drainage.

## Design Features

* Four-way roadway intersection
* Multiple travel lanes
* Dedicated left-turn lanes
* Centerline markings
* Lane-separation markings
* Stop bars
* Pedestrian crosswalks
* Sidewalks
* ADA curb ramps
* Traffic signals
* Traffic-control signs
* Storm-drain inlets
* Roadside landscaping
* Conceptual vehicle placement

## Design Considerations

The intersection was designed to visually separate through movements and turning movements while providing designated pedestrian crossing locations.

Crosswalks and curb ramps create pedestrian connections between each corner of the intersection.

Traffic signals and pavement markings demonstrate conceptual traffic-control infrastructure.

Storm-drain inlets located near the roadway edges represent drainage collection points for roadway runoff.

## Software

**OpenSCAD**

Parametric geometry, reusable modules, transformations, and loops were used to construct roadway elements and transportation infrastructure.

## Viewing the Animation

This model includes a built-in 360° camera animation.

1. Open the `.scad` file in OpenSCAD.
2. Press **F5**.
3. Select **View → Animate**.
4. Set **FPS:** `30`
5. Set **Steps:** `180`
6. Play the animation.

The animation uses OpenSCAD's `$t` variable to rotate the camera around the intersection.
