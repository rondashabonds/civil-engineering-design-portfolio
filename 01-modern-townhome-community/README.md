# Modern Townhome Community

## Project Overview

The Modern Townhome Community is a conceptual residential site-development project created in OpenSCAD.

The project explores the relationship between residential buildings, internal roadways, pedestrian infrastructure, parking, landscaping, and community amenities within a planned development.

## Design Features

* Multi-story modern townhomes
* Private garages and driveways
* Large windows
* Balconies
* Rooftop terraces and pergolas
* Internal roadway system
* Sidewalk network
* Guest parking
* Landscaped entrance
* Clubhouse
* Community swimming pool
* Dog park
* Street lighting
* Trees and landscaped areas
* Community entrance monument

## Design Considerations

The site was organized to provide clear vehicle circulation while maintaining pedestrian connections between residential buildings and shared amenities.

Townhome rows are arranged around an internal roadway network, with sidewalks providing pedestrian connections throughout the community.

Shared recreational spaces were placed near the center of the development to create a central amenity area accessible to residents.

## Software

**OpenSCAD**

The model was created parametrically using 3D primitives, transformations, reusable modules, loops, and custom site elements.

## Viewing the Animation

This model includes a built-in 360° camera animation.

1. Open the `.scad` file in OpenSCAD.
2. Press **F5**.
3. Select **View → Animate**.
4. Set **FPS:** `30`
5. Set **Steps:** `180`
6. Play the animation.

The animation uses OpenSCAD's `$t` variable to rotate the camera around the development.
