# Small Site Development Plan

## Project Overview

This project is a conceptual small commercial site-development plan created in OpenSCAD.

The design explores fundamental site-development considerations including building placement, parking, vehicle circulation, pedestrian access, accessibility, landscaping, and stormwater management.

## Design Features

* Modern commercial building
* Parking areas
* Internal drive aisles
* Public roadway connection
* ADA parking spaces
* Accessible pedestrian route
* ADA curb ramp
* Sidewalks
* Landscaped curb islands
* Site lighting
* Trees and landscaping
* Storm-drain inlets
* Conceptual stormwater detention area
* Conceptual drainage outlet

## Design Considerations

The building is positioned toward the rear of the site while parking and vehicle circulation occupy the central portion of the property.

Pedestrian infrastructure connects the parking area with the building entrance.

Accessible parking spaces are located near the building and connect to an accessible pedestrian route.

Storm-drain inlets are positioned throughout the paved areas as conceptual collection points for surface runoff. A detention area represents an approach to managing stormwater generated by the developed site.

## Software

**OpenSCAD**

The model uses reusable modules and parametric geometry to represent buildings, pavement, sidewalks, parking spaces, drainage infrastructure, landscaping, and other site elements.

## Viewing the Animation

This model includes a built-in 360° camera animation.

1. Open the `.scad` file in OpenSCAD.
2. Press **F5**.
3. Select **View → Animate**.
4. Set **FPS:** `30`
5. Set **Steps:** `180`
6. Play the animation.

The animation uses OpenSCAD's `$t` variable to rotate the camera around the site.
